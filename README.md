# ianyarko.github.io

My portfolio: free phone apps for everyday Ghanaian life, made in Accra.

- [Pocket Cedi](https://ianyarko.github.io/pocket-cedi/) – spending tracker
- [Run Walk Cycle](https://ianyarko.github.io/run-walk-cycle/) – running coach
- [Morphē](https://ianyarko.github.io/morphe/) – daily progress photos
- [Chop Week](https://ianyarko.github.io/chop-week/) – weekly meal planner
- Wetin I Go Chop – food decider (coming soon)

Built by Immanuel Adom Nyarko, with Claude as coding partner. Visits are counted with GoatCounter (no cookies, no personal data).
